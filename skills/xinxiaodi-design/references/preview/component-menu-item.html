标准列表项
Figma 7559:42913 / 7559:42918 · 通用导航页（功能选择页 Hub）的纵向入口行：左侧「24px 图标 + 文字」，右侧「16px 右箭头」，白底圆角卡片行。图标与文字随业务场景变化，结构固定。
返空柜
其他异常
列表容器 .menu-list（gap 12px），行 .menu-item（白底 10px 圆角，padding 16px → 行高 56px）；点击整行跳转对应功能页
使用约束
该组件的适用范围有严格限制。
仅用于「通用导航页（功能选择页 Hub）」里的列表项。
当某业务的子功能 ≥ 3 个、需要一个二级入口集合页时，用 .menu-list + .menu-item 纵向罗列各入口（如异常提报页的「返空柜 / 其他异常」）。
不要用于以下场景：卡片内部行、Tab 内容区、表单字段行、列表页的运单/业务卡片、设置项开关行等。这些场景应使用对应的卡片、表单、选择器等组件，不得借用 menu-item。
